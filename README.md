# IVTS Firmware Training

Tài liệu từng bước để dựng lại firmware IVTS trên ESP32-S3 từ codebase tham chiếu.

## Stack

- Docusaurus 3.10.1
- React 19
- GitHub Actions
- GitHub Pages

## Chạy local

```powershell
npm ci
npm start
```

## Kiểm tra production build

```powershell
npm run build
npm run serve
```

Website được deploy tự động từ branch `main` bằng workflow GitHub Pages.
